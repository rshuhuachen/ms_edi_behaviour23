## Scripts

In this folder, all scripts are stored that are used to generate results and tables, in addition to the scripts stored in the `qmd` directory.

The ggplot theme of the manuscript, functions that were used to run models and script to generate the main figures of the manuscript are stored in the main folder. The subdirectories with additional scripts are divided by the sections of the manuscript: `question-asking` refers to all analyses on question-asking behaviour (observational and post-congress survey), `experience` refers to congress experience related analyses(post-congress survey), and `issue_perception` refers to the perception of EDI issues (post-congress survey)
