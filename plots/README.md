## Plots

In this directory, you will find the plots used for the manuscript. In the `main` directory, you will find the main figures used in the manuscript that are generated through R. Within the subfolder `single`, the panels of each plot are split out.

There are two main plots that are made using Lucid, a web-based tool. These plots can be found starting with the name 'diagram' within the `main` directory.

The `supplementary` directory contains additional plots used in the Appendices. The plot in the `collect_summarize` directory was taken out of the manuscript, but shows the distribution of congress registrants.
